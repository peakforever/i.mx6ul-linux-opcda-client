## 本轮可靠性优化

当前采集语义经用户后续确认变更，详见 [单点隔离规格](dev-spec-point-isolation.md)。

依据：[优化建议](optimization-review-2026-11-11.md)、[实施规格](dev-spec-optimization-2026-11-11.md)、[缺陷案例](lessons/2026-11-11-reliability.md)。

| 建议 | 当前实现与边界 |
|---|---|
| O1 重连可停止 | 独立发布停止信号，取消退避；首次连接及重连在连接/绑定返回后检查停止，候选不再发布。关闭仍等待不响应中断的第三方 RPC 返回；未承诺立即退出。 |
| O2 ItemID 原文 | 空白检查保留；存储、去重、绑定与 MD5 使用原文，不再 trim。 |
| O3 单点隔离 | 用户确认后改为每次读取结束转发本轮可用点；缺失/失败点不阻断其他点，不补旧值；已绑定点恢复后自动参与后续轮次。显式周期边界、相同状态逐轮交付、丢弃旧连接回调；保留缺失摘要和恢复日志，不因单点缺失重连全连接。 |
| O4 心跳来源 | 用户确认应答来源后，接收层过滤配置目标 IP/端口；错误来源不重置本次接收超时预算，保持 UDP 发送行为。 |
| O5 打包权限 | 私有暂存权限，包内 points.json 与最终归档均为 600，输出原子替换；失败保留旧包并清理临时输出。保留此前默认 runtime 路径改动。 |
| O6 运行状态 | 采集主循环每 60 秒汇总连接、快照时间/年龄、停滞数、发送增量、累计跳过/失败及心跳在线状态。最近轮次计数为本轮收到的点数。同步重连期间主循环摘要会暂停，重连过程仍有原有日志。 |
| O6 重复告警 | 坏记录日志按 sender 总跳过数采样：首次和每 100 次输出最新失败样本；累计计数完整。不是逐点错误清单，也不承诺每种错误都有独立日志。 |
| O8 点位查找 | 集合检查成员，列表保留发送顺序；不引入队列或改动组包协议。 |
| O9 状态记录 | README 指向当前状态，修正默认字符集为 UTF-8；历史路线图增加历史标记，当前测试数同步。 |
| O10 退出异常 | 沙箱内复现；允许本机监听的完整构建未复现。依赖异步创建 resolver socket，启动 IOException 被吞掉，关闭又未检查 null，符合环境限制触发路径。未修改 J-Interop，不宣称现场启停已验证。 |

发送计数表示本机 UDP send 成功，不代表接收端送达。缺失点摘要只描述最近一次结束的读取轮次，不代表对应点位整个告警期间从未回调。周期接收计数不代表全部可编码，非数值记录由 sender 单点跳过。
